# begining

這是一個起始專案，用來放個人筆記、設定與小工具的整理文件。

## 專案結構

```
begining/
├── README.md                 專案說明（本檔案）
├── .gitignore                Git 忽略規則
└── docs/
    └── graphify-setup.md     graphify 安裝與設定說明
```

## 文件

- [graphify 安裝與設定](docs/graphify-setup.md)：如何安裝 graphify，並把它註冊成 AI 助理（例如 Claude Code）的 `/graphify` Skill。

## 使用方式

```
git clone https://github.com/cobwebox-cmd/begining.git
cd begining
```

之後依需求閱讀 `docs/` 底下的文件。
